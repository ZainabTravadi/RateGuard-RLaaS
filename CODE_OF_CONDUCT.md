# Code of Conduct

## Our Pledge

We are committed to making this project a respectful, constructive place to contribute. Everyone who participates in issues, pull requests, reviews, and discussions should expect to be treated with courtesy.

## Standards

Examples of behavior that helps the community:

- Being respectful and concise in feedback
- Focusing on the work, not the person
- Sharing context when asking for help
- Acknowledging when someone improves the repository

Examples of behavior that does not belong here:

- Harassment or personal attacks
- Deliberate disruption
- Dismissive or abusive language
- Sharing secrets or private data without permission

## Enforcement

Maintainers may remove or hide content that violates this code of conduct and may limit participation in the repository when needed to keep the project productive and safe.

## Scope

This code of conduct applies to repository issues, pull requests, discussions, review comments, and any other project-maintained communication channel.

## Reporting

If you experience behavior that violates this code of conduct, document the issue and contact the maintainers through the repository's private support or security channels.
