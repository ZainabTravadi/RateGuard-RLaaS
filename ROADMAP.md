# Roadmap

This roadmap separates shipped work from the next set of improvements so contributors can see what is real today and what is still being built.

## Completed

- Node.js SDK with builder, client, policy, plugin, logging, observability, and error APIs.
- CLI commands for initialization, diagnostics, policy simulation, analytics, export/import, benchmarking, and migrations.
- Backend API with health, enforcement, analytics, auth, rules, API key, workspace, environment, and gateway modules.
- Dashboard UI with overview, analytics, logs, rules, integrations, settings, notifications, and authentication screens.
- Framework adapters for Express, Fastify, NestJS, Next.js, Koa, Hono, Bun, Deno, and Cloudflare Workers.

## In Progress

- Documentation standardization across the whole workspace.
- Further refinement of deployment and troubleshooting guidance.
- More examples that mirror the current API and CLI behavior.

## Future

- Additional observability exporters and dashboard views.
- More policy management tooling and reporting workflows.
- Release automation improvements for published packages.
- Broader production deployment examples and hardening guidance.

## Notes

- The roadmap should stay aligned with the repository, not wishful planning.
- When a feature ships, move it to `Completed` and link to the implementation or release notes.
